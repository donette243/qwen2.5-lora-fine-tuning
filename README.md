# Fine-tuning Qwen2.5 с использованием LoRA и PEFT

## О проекте

Проект посвящён адаптации языковой модели **Qwen2.5-0.5B-Instruct** для автоматического формирования кратких аннотаций товаров на русском языке.

Fine-tuning реализован с использованием **LoRA (Low-Rank Adaptation)** и библиотеки **PEFT**, что позволяет адаптировать предобученную языковую модель, обновляя только небольшую часть её параметров.

В рамках проекта реализован полный экспериментальный цикл: подготовка данных, обучение, валидация, сохранение адаптера и сравнительная оценка качества генерации до и после fine-tuning.

## Технологии

- Python
- PyTorch
- Hugging Face Transformers
- PEFT / LoRA
- Qwen2.5-0.5B-Instruct
- CUDA

## Реализация

### Подготовка данных

Сформирован синтетический набор из 96 примеров товарных описаний, распределённых по восьми категориям.

Данные разделены на три выборки:

| Выборка | Количество |
|---|---:|
| Обучающая | 48 |
| Валидационная | 24 |
| Тестовая | 24 |

Для проверки обобщающей способности модели в валидационной и тестовой выборках использованы бренды, отсутствующие в обучающей выборке.

### Fine-tuning LoRA

Для адаптации модели использована библиотека PEFT с настройкой низкоранговых матриц в слоях внимания.

Основные параметры:

| Параметр | Значение |
|---|---|
| Базовая модель | Qwen2.5-0.5B-Instruct |
| Метод | LoRA |
| LoRA rank | 4 |
| LoRA alpha | 8 |
| Целевые модули | q_proj, v_proj |
| Learning rate | 0.00015 |
| Эпохи | 5 |
| Gradient accumulation | 8 |
| Максимальная длина последовательности | 256 токенов |
| Оборудование | NVIDIA GeForce GTX 1650 Ti, 4 ГБ VRAM |

Для снижения потребления видеопамяти применены FP16, gradient checkpointing и накопление градиентов.

### Валидация и оценка

В процессе обучения отслеживалась ошибка на обучающей и валидационной выборках. Лучший адаптер сохранялся для последующей оценки.

Качество оценивалось на отдельной тестовой выборке по трём показателям:

- Точное совпадение с эталонной аннотацией.
- Сохранение полного названия бренда и модели.
- Сохранение указанной характеристики товара.

## Результаты

| Метрика | До fine-tuning | После fine-tuning |
|---|---:|---:|
| Точное совпадение | 0% | **79,17%** |
| Сохранение бренда и модели | 75% | **100%** |
| Сохранение характеристики | 41,67% | **100%** |

Результаты получены на тестовой выборке из 24 синтетических примеров.

### Пример генерации

**Входные данные:**

```text
Монитор Dell UltraSharp, 24 дюйма
```

**До fine-tuning:**

```text
Название: Dell UltraSharp 24 дюймовый монитор
```

**После fine-tuning:**

```text
Монитор Dell UltraSharp с характеристикой 24 дюйма.
```

**Эталон:**

```text
Монитор Dell UltraSharp с характеристикой 24 дюйма.
```

После адаптации модель стала точнее соблюдать заданный формат и сохранять исходные характеристики товаров в рамках тестового набора.

## Запуск

### 1. Создание виртуального окружения

```bash
python -m venv .venv
```

### 2. Активация в Windows

```cmd
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install torch transformers peft accelerate safetensors
```

Для обучения на GPU необходима совместимая с CUDA сборка PyTorch.

### 4. Запуск обучения

```bash
python train_lora.py
```

После завершения обучения сохраняются адаптер LoRA и файл `evaluation_qwen.json` с историей обучения, метриками и примерами генерации.

## Ограничения

Эксперимент выполнен на небольшом синтетическом наборе данных с однотипными аннотациями. Полученные метрики демонстрируют результат адаптации в рамках конкретной задачи, но не подтверждают качество модели на реальных товарных каталогах.

Для дальнейшего развития проекта планируются расширение датасета, использование реальных товарных описаний и дополнительная оценка фактической точности генерации.
